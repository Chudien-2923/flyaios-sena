# Jobs

Tạo một file `jobs/YYYY-MM-DD-<ten-viec>.md` khi bạn có công việc dựng video cần theo dõi qua nhiều phiên; không cần tạo file cho các câu hỏi nhanh hoặc thử nghiệm nhỏ. Liên kết mọi job từ [[WORK]].

## Gợi ý nội dung một file job gọn

- **Mục tiêu & đầu ra:** loại video (SaaS / vlog / talking head / short-form), nền tảng, tỷ lệ khung hình, thời lượng dự kiến.
- **Đường dẫn project video (ngoài repo Sena):** thư mục chứa footage, mã nguồn dựng và file xuất trên máy bạn.
- **Quyết định đã chốt vs bản nháp:** storyline đã chọn, phong cách màu/chữ/nhạc, các vòng feedback.
- **Trạng thái kiểm chứng:** thông số `ffprobe`, kết quả nhìn frame, mức âm thanh đã đo và phần còn cần xử lý.
- **Bước tiếp theo:** đầu việc rõ ràng để lần sau mở lại phiên làm tiếp ngay.
