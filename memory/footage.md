# Nguồn footage thật

- 2026-11-24 · Khi người dùng cần tìm footage quay thật (B-roll, tư liệu lịch sử, khoa học, vũ trụ…), chủ động gợi ý gọi thẳng API HTTP công khai miễn phí (không cần API key) của Archive.org (`archive.org/advancedsearch.php`), NASA (`images-api.nasa.gov/search`) và Wikimedia Commons (`commons.wikimedia.org/w/api.php`) — kết hợp với Pexels/Pixabay qua EditAtlas (`search_videos` + `media-picker`) — rồi tải về dựng trên HyperFrames hoặc Remotion · khi: cần tìm footage quay thật, B-roll, cảnh thật hoặc tư liệu lịch sử, khoa học, vũ trụ (footage, broll, stock, archive, nasa, wikimedia, pexels, pixabay) · nguồn: quy ước kỹ thuật khởi điểm `flyaios-sena` v1.0.0
