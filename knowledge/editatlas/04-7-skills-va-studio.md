# EditAtlas — 7 Skills cục bộ và EditAtlas Studio

7 skill của `EditAtlas/skills` được cài theo nhánh harness trong [[SETUP]]. Luôn mở đọc `SKILL.md` gốc trước khi chạy bước tự động, và đặt `EDITATLAS_TELEMETRY=0` khi chạy script chính để tắt telemetry.

## 2. EditAtlas Web Studio (`https://edit.trysometh.ing/studio`)

- **Cơ chế:** trình duyệt mở trực tiếp thư mục project cục bộ (`project.json` + media) bằng WebCodecs & File System Access API → **footage không bao giờ rời khỏi máy người dùng**. Lưu mỗi lần tạo version mới để người dùng và agent luân phiên chỉnh tiếp.
- **Trình duyệt yêu cầu:** Chrome hoặc Edge **≥ 94** (Safari và Firefox chưa được EditAtlas kiểm thử).
- **Lỗi đường dẫn hay gặp trên Chrome:** Chrome chặn mở thư mục nằm trong `/tmp`, `Temp`, `AppData` hay thư mục hệ thống — đặt thư mục project trong `Documents`, `Videos` hoặc Desktop.
- **Tính năng chỉnh nhanh:** di chuyển/trim clip, tách clip (`S`), nhân đôi (`Ctrl+D`), thêm chữ/media/ghi chú cho agent (`Add note`), phát lặp/từng frame (`J/K/L`, `← →`), xuất MP4 ngay tại trình duyệt (`Export MP4`).
- **Tùy chọn Google Drive / tài khoản:** hoàn toàn không bắt buộc. Sena không tự thao tác đăng nhập Google hay bật đồng bộ Drive; người dùng tự đăng nhập trong trình duyệt nếu muốn dùng link chia sẻ mã hóa.
